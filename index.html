Versión inicial 1.0

¿Qué incluye esta versión?

Una primera versión funcional para probar cálculos frecuentes en agronomía.

✓ Calculadora de dosis por área y tanque.
✓ Calculadora de fertilizante según concentración nutricional.
✓ Densidad de siembra con distancias entre surcos y plantas.
✓ Registro básico de datos de ensayos y promedios por tratamiento.
✓ Estimación sencilla de costos por hectárea.

Antes de usar

Esta herramienta apoya cálculos; no reemplaza el criterio profesional ni la validación técnica.

Para plaguicidas, ingresa únicamente dosis verificadas en la etiqueta y autorizadas para el cultivo y uso correspondiente en Colombia. Respeta restricciones, EPP, intervalos de reingreso y carencia.
